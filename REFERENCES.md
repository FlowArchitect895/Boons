# Reference directory

Primary external resources used by the Boons guides. Links identify useful
upstream projects and documentation; inclusion is not an audit, endorsement,
compatibility guarantee or claim that an integration has been tested.

## Maintenance

- Prefer primary repositories and official documentation.
- Verify commands, supported clients, licensing and compatibility before use.
- Recheck version-sensitive details when updating the guides.
- External projects are independently maintained; consult their own security
  advisories, release notes and support policies.
