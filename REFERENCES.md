# Reference directory

This is a short list of primary project and documentation links used by the Boons guides. Inclusion means the resource is relevant—not that Boons audits, owns, or guarantees it.

## Boons and distribution

| Resource | Use |
|---|---|
| [Boons GitHub](https://github.com/FlowArchitect895/Boons) | Source of the six Boons skills, package checks, and experiment record |
| [Boons on Agensi](https://www.agensi.io/skills/boons) | Marketplace distribution and MCP-based access |
| [Agensi MCP documentation](https://www.agensi.io/docs/mcp-server) | Current connection, OAuth, endpoint, and account guidance |
| [Agent Skills specification](https://agentskills.io/) | Portable skill format and conventions |

## Maintenance

- Prefer primary project repositories and official documentation over third-party setup summaries.
- Verify installation commands, supported clients, licensing, and compatibility before recommending them.
- Record a verification date when adding version-sensitive instructions.
- If a link or feature changes, update the relevant guide and note what was rechecked.
- External projects are independently maintained. Their presence here is not an endorsement or security audit.
